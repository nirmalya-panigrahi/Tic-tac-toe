# NP Tic Tac Toe

## Project Overview
This repository contains a modern implementation of the classic game Tic Tac Toe using various technologies to enhance the gaming experience.

## Features
- **Multiplayer Support**: Play against friends or AI.
- **Responsive Design**: Works seamlessly on both web and mobile devices.
- **User Authentication**: Optionally sign in to save scores.
- **AI Difficulty Levels**: Challenge yourself against different levels of AI.

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **Database**: MongoDB

## Setup Instructions
1. **Clone the Repository**: 
    ```bash
    git clone https://github.com/nirmalya-iitkgp/np-tic-tac-toe.git
    cd np-tic-tac-toe
    ```
2. **Install Dependencies**: 
    ```bash
    npm install
    ```
3. **Run the Application**: 
    ```bash
    npm start
    ```

## Usage
- Navigate to the application in your browser at `http://localhost:3000`
- Choose your game mode (Single Player or Multiplayer) and start playing!

## Deployment
- To deploy the application, you can use services like Heroku, Vercel, or Netlify. Follow the respective service’s documentation for deployment instructions.
